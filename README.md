# Markito

A lightweight multi-page landing site for **Markito**, a market-intelligence concept focused on surfacing useful public-market signals without the noise.

## Pages
- Home
- Features
- How it works
- Pricing
- Sources
- About

## Stack
Plain HTML, CSS and JavaScript. No build step and no login/dashboard.

> Markito is an early-stage concept. Market information is for informational purposes only and is not financial advice.
